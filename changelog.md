# Changelog

Notable user-facing changes to Block Fall are recorded here. Versions correspond to the `version` field in `manifest.json`.

## [1.2.3]

- Simplified the ready screen to show the centered **Start game** button without the previous introductory headline and description.
- Simplified the pause overlay to show a centered **Resume game** button.
- Kept the game-over state and replay action.

## [1.2.2]

- Inverted the app logo artwork to use a near-black background with a white Tetris block mark.
- Regenerated the PNG logo exports at the supported icon sizes and updated the packaged extension version.

## [1.2.1]

- Added the dark, minimal Block Fall logo as an SVG asset.
- Added PNG icon exports for use in Chrome's extension toolbar and extension surfaces.

## [1.2.0]

- Built Block Fall as a Manifest V3 Chrome extension using Chrome's native side panel.
- Added the 10 × 20 playfield, seven-piece bag, ghost piece, hold slot, and next-piece previews.
- Added movement, rotation, soft drop, hard drop, line clearing, scoring, level progression, pause, resume, restart, and game-over behavior.
- Added score, level, line count, and personal-best indicators.
- Added keyboard and on-screen controls.
- Added System, Light, and Dark themes with locally saved theme preference.
- Added locally saved personal-best score, accessibility focus states, and reduced-motion support.
